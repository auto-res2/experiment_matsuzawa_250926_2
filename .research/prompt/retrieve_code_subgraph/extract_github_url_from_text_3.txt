# Paper Outline
DyHPO employs a Gaussian Process (GP) surrogate model using a novel deep kernel. This kernel, K, is defined as k(φ(xi, Yi,j-1, j; w), φ(xi', Yi',j'-1, j'; w); θ), where k is a squared exponential kernel. The feature extractor neural network (φ) takes as input the hyperparameter configuration (xi), the normalized budget (j), and the past learning curve (Yi,j-1). φ is composed of linear layers and a one-dimensional convolutional layer followed by global max pooling for processing the learning curve. The optimal parameters for the kernel and neural network are found by maximizing the marginal likelihood using gradient descent (Adam). For candidate selection, DyHPO introduces a Multi-Fidelity Expected Improvement (EIMF) acquisition function, which extends the standard Expected Improvement by considering the largest observed performance for a given budget or any budget. The algorithm iteratively selects the most promising candidate to train for one additional budget step, observes its performance, and updates the surrogate model.
