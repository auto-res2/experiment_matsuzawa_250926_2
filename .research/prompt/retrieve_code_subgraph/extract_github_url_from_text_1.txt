TENT optimizes the pre-trained model during testing by minimizing the Shannon entropy H(ˆy) of its predictions ˆy = fθ(xt). This objective is unsupervised, depending only on predictions. The adaptation is achieved by modulating features through linear (scales and shifts) and low-dimensional (channel-wise) transformations, specifically by updating the normalization statistics (mean µ and standard deviation σ) and affine transformation parameters (scale γ and shift β) of Batch Normalization layers. The algorithm initializes by collecting γ and β for all normalization layers, discarding source statistics, and fixing all other model parameters. During iteration, normalization statistics are estimated on the current batch during the forward pass, and γ, β are updated using the gradient of the prediction entropy during the backward pass. This process is online, continuing as long as test data is available, or can be run for a fixed number of epochs for offline adaptation. The model must be probabilistic, differentiable, and pre-trained for the supervised task.
