# Paper Outline
DA-Pro leverages a pre-trained Vision-Language Model (VLM) like CLIP as a robust detection backbone. The core methodology involves generating a domain-aware detection head by learning a domain-adaptive prompt. This prompt consists of four components: M learnable domain-invariant tokens (Vc) to capture common knowledge, N learnable domain-specific tokens (Vd) to exploit domain-specific knowledge, tokenized class vectors (ci) for discriminative representation, and hand-crafted domain-related textual description vectors (dld) to embed domain-specific information. Two constraints guide the prompt learning: (1) an 'invariant' constraint (Linv_d) where detection heads generated by both source and target prompts classify source images as accurately as possible, learning shared knowledge; and (2) a 'specific' constraint (Lspc_d) where the detection head of a domain outputs higher confidence for images from its own domain, learning domain-specific knowledge. For the unlabelled target domain, pseudo labels are generated using a zero-shot CLIP approach with a probability threshold. The overall training objective combines source and target losses (Ls and Lt), with Lt also including an information entropy minimization (Lent). A historical prompts ensemble strategy using Exponential Moving Average (EMA) is employed to stabilize prompt tuning by averaging history prompts.
