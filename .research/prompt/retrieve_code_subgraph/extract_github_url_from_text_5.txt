# Paper Outline
The methodology revolves around two core strategies. First, a learnable consistency loss (Lwcont) is introduced for the TTT task. Instead of a heuristically defined objective, Lwcont employs a weight subnetwork (fw) to measure consistency between representations (z, z') from a feature extractor and its augmented version. The parameters of fw are updated by enforcing alignment between the normalized gradients of Lwcont and the main classification loss (Lmain) with respect to the feature extractor. Second, during the test-time adaptation phase, additional adaptive parameter blocks (fΘ) are inserted after each block of the pretrained feature extractor. Only these newly introduced adaptive parameters (fΘ) are updated using the learned consistency loss, while the original model parameters remain fixed. This online updating strategy adapts the model to unseen target domains.
