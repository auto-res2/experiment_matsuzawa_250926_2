# Paper Outline
DNN-MFBO employs a multi-fidelity model built with stacked deep neural networks, where each NN models one fidelity. For fidelities beyond the first, the input to an NN includes both the original input and the output from the previous fidelity to propagate information and capture complex inter-fidelity relationships. The weights in the output layer of each NN are treated as random variables with a standard normal prior, while all other weights are hyper-parameters. A stochastic variational learning algorithm is developed to jointly estimate the posterior of these random weights (approximated by a multivariate Gaussian) and the hyper-parameters, maximizing an evidence lower bound (ELBO) using the reparameterization trick. For optimization, a mutual information-based acquisition function is used, defined as the benefit-cost ratio. To compute this function, the output posteriors in each fidelity are approximated as Gaussian distributions using fidelity-wise moment matching and Gauss-Hermite quadrature. The entropy terms in the acquisition function are computed using Monte-Carlo approximations and further moment matching to approximate conditional distributions as Gaussian.
